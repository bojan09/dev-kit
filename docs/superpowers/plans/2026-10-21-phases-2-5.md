# DevKit Phases 2–5 Implementation Plan

User authorizes continuous execution through final audit. All commits push to master only. Existing remote phase-1 branch is preserved.

## Phase 2

- Reproduce and fix live dashboard favorites and Escape menu label with browser regressions.
- Test then implement pure JSON, Base64, UUID, timestamp, URL and text modules.
- Introduce shared workspace renderer/controller, safe editors, options, validation, reset, clipboard/export and lifecycle cleanup. Preserve non-secret drafts/options in session memory only.
- Validate deterministic edge vectors and browser tool workflows. Update report, commit and push master.

## Phase 3

- Test then implement rejection-sampled Web Crypto passwords and secure shuffle; no secret storage/history.
- Run regex in disposable workers with size, match and time limits; safe highlighted text/capture rendering, zero-width advancement and termination on navigation.
- Audit rendering, preferences, capabilities and secret lifecycle. Test, document, commit and push master.

## Phase 4

- Compare actual desktop/tablet/mobile and light/dark screenshots to supplied reference. Refine compact tool header, split editors, state feedback, token contrast and touch sizes.
- Run keyboard, focus, reduced-motion and automated accessibility checks. Fix verified issues and retain evidence. Commit and push master.

## Phase 5

- Add local install icons, manifest, versioned shell-only service worker and update prompt. Never cache user inputs/outputs or arbitrary requests.
- Test offline reload/deep links, update/cache cleanup where feasible, clipboard/export, disabled storage, worker recovery and secure APIs.
- Final UI/UX, performance and source/security audit; independent reviewer; finish README/privacy/limitations/test matrix and phase report. Record precise measured results and unperformed hardware/browser checks.
- Commit and push master. Deploy only if authorized/configured; pushing source does not enable hosting.

Interfaces: each pure module exports run(input, options) returning output/status and optional structured match metadata. Registry lazily loads modules. Shared mountWorkspace(container, context) returns cleanup; context supplies validated preferences, in-memory state and announcements. Route changes dispose timers/workers/listeners. Non-secret drafts are Map values; password values never enter that Map.
