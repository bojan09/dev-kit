# Tool limitations

| Tool           | Limits and behavior                                                                                                                                                                                                                                                                                                                                                  |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Shared editors | 1,000,000 input UTF-16 code units; 4,000,000 output code units. No auto-save to persistent storage. Line-number gutter is capped at 5,000 logical lines and wraps are logical, not visual line numbering.                                                                                                                                                            |
| JSON           | Native JSON.parse/JSON.stringify. Large integers can lose precision; duplicate keys keep the last value. Error position/line/column is shown only when browser error text supplies a reliable numeric position.                                                                                                                                                      |
| Base64         | Standard alphabet and canonical = padding, not Base64URL. Whitespace is accepted on decode. Invalid UTF-8 is rejected. TextEncoder follows standard replacement behavior for unpaired UTF-16 surrogates on encode.                                                                                                                                                   |
| UUID           | v4 only, 1–100 per run. crypto.randomUUID requires a supported secure context; there is no insecure fallback.                                                                                                                                                                                                                                                        |
| Timestamp      | Explicit integer Unix seconds/milliseconds or four-digit-year ISO with seconds and Z/offset. Up to three fractional second digits. Calendar fields and overflow are validated; output uses the browser’s timezone for local display.                                                                                                                                 |
| URL            | Encode/decode is for components, not whole-URL rewriting. Inspection never visits a URL; query pairs preserve duplicates.                                                                                                                                                                                                                                            |
| Text           | Characters are code points, not grapheme clusters; words split on whitespace. Locale-independent case and heuristic title/sentence case. CRLF/CR normalize to LF. Sorting uses UTF-16 order and deduplication is exact-line comparison.                                                                                                                              |
| Password       | 8–128 characters; selected categories each appear. Web Crypto only, rejection sampling and secure shuffle. No strength/entropy guarantee; device/clipboard security is outside app control.                                                                                                                                                                          |
| Regex          | Native JavaScript syntax/flags supported by your browser. Disposable worker; 750 ms timeout; 500-character pattern, 50,000-character sample, 500-match threshold and 200,000 aggregate match/capture characters. Offsets are UTF-16. Non-global/non-sticky expressions report one match. A pathological expression can consume resources briefly before termination. |

Secure APIs and service workers require HTTPS or localhost. Offline use requires a successful first shell installation; browser private modes, storage quotas or site-data clearing can disable it. Native OS installation, physical mobile touch and screen-reader walkthroughs require checks on actual devices. Firefox and WebKit are not verified in this environment.
